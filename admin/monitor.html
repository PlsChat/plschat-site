🎛 Sensors and inputs

Readings arrive by radio through the company unit plugged into this PC, encrypted with your company key. Click any name or label to rename it here, Customise chooses which boxes show, and Set up shows what is switched on in the unit and lets you change it from here with a command signed by the server for that one unit.

How to set this up (company key, switches, relays, sensors)

1. Company key — do this first, on every company unit

  • It is one passphrase of 12 or more characters that you choose. Each unit turns it into an encryption key and keeps it.
  • Readings are encrypted with it before they go on the air. Customer devices pass them along but cannot read them. A unit with a different key (or none) is simply not shown here.
  • Set it either here (Company key button, one unit at a time over USB) or on the unit's own page: I/O tab → Company key. Use exactly the same passphrase on all of them.
  • It is never sent to the server and never saved in this page. Keep a copy somewhere safe — it cannot be read back out of a unit.

2. Tell each unit what is wired to it (on the unit, or from here)

  1. Join the unit's WiFi (PLSChat-xxxx), open 192.168.4.1, unlock it and open the I/O tab (company units only).
  2. Tick what is fitted, give each thing a name, choose its pin, press Save. Only ticked items are sent, so a unit with nothing ticked shows just Battery, Licence, Tamper and Signal here.
  3. Or do it from this page: press Set up on the unit's card. It shows what the unit has now; change it and press Send to device. The server signs the change for that one unit and the unit confirms. Works over the mesh, needs the write key and v007.17 or newer. The company key cannot be changed this way.

3. Wiring

  • Switch / door contact / alarm output (Input 1, Input 2): wire a volt-free contact between the input pin and GND. Closed = ACTIVE. Never put a voltage on the pin.
  • Relay timers and modes (Relays tab → Set up): Inching switches off again by itself after a set time; Daily schedule switches on and off at set times on chosen days; Local switch lets a button on an input work the relay at the unit; Interlock stops both relays being on together.
  • Relay 1, Relay 2: the pin drives the IN terminal of a 3.3 V relay module (with its own transistor or opto) — never a bare relay coil. Power the module from 5 V / GND. If the relay is on when it should be off, tick Active low. Choose what it does after a restart: off, on, or as it was.
  • Temperature / humidity / pressure: a BME280 board on 3.3 V, GND, SDA and SCL.
  • Wind: a pulse (reed switch) anemometer between the wind pin and GND. Enter its mph per pulse-per-second from the sensor's data sheet.
  • The default pins are a first guess for the Heltec V4 — check them against your board before wiring.

4. Using this page

  • Plug any one company unit into this PC and press Connect a device. Every unit it can hear appears as a card. Units report every 5, 15 or 60 minutes, at once when something changes, and when you press Report now.
  • Relay switches need the write key: the server signs each command for one unit. The switch shows “sent, waiting” until that unit confirms.
  • Click a device name or a box label to rename it. Customise chooses which boxes show. These are saved in this browser only.

🏭 Company Firmware — v007

Tamper-enabled build • ESP32-S3

Flash the v007 firmware to a company device. Hold the BOOT button on the Heltec while clicking Connect in the installer. After flashing, provision it with COMPANY:ON over serial to enable the tamper module.

Note: the company firmware is served from a private store (/admin/fw/, Cloudflare Access only) — it is not in the public repo. Once a device has secure boot + flash encryption enabled (Release mode), it can no longer be reflashed here — that's expected. Clicking Connect automatically releases the Licence Manager's serial connection first, so you don't need to refresh between sections.

Company XIAO: I/O pins are GPIO2 (D1), GPIO3 (D2), GPIO5 (D4) and GPIO43 (D6). A pin given to I/O is taken from the vibration motor (D1) or external LED (D2). Use D6 for an input, not a relay — it pulses at power-up. No screen on company XIAO units. GPIO4 (D3) is the lid switch, so buzzer leg 2 goes to GND. Units wired with the radio on the header pins cannot use I/O. After flashing, enable company mode on the Company & tamper tab.

Test checklist (v2.74 + v007.17)
  1. Flash without erasing. Unlock: contacts, rooms, messages and settings are still there. The v2.70 tests (clock, quiet hours, Settings tabs) still pass.
  2. Licence over the mesh: plug in device A, leave device B on battery in another room. Licences tab → type B's MAC → Generate → Send over the mesh. Expect “installed” within about 30 s, and B's Licence page shows the new expiry. Works while B is locked.
  3. Send B's licence a second time → still “installed”. A licence made for a different MAC never reaches B and times out after 6 tries.
  4. v007.13 I/O tab (company units): set the same Company key on two units, tick the sensors / inputs / relays that are wired, Save. The tiles update every few seconds.
  5. With one unit plugged in here: Devices tab → Connect a device. Both units appear within a minute; rename one and a label, reload the page → names kept.
  6. Short an input pin to GND on the far unit → its tile changes here within a few seconds.
  7. Flip a relay switch here → “sent” then “confirmed”, and the relay clicks. Flip it on the unit's own page → this page follows.
  8. A consumer device (v2.71) between the two company units passes the reports on but shows nothing itself.
  9. v007.14 remote set-up: on a far unit's card press Set up → tick Input 1, give it a name → Send to device. Expect “confirmed”, the new box appears, and the unit's own I/O tab shows the same. Two things on one pin are refused.
  10. v007.14: the unit's own page now has separate I/O and Relays tabs; saving one does not change the other.
  11. v007.15 company XIAO: flash a XIAO from the Company section, enable company mode, set the company key. Its card appears here; Set up offers only the XIAO pins. Tick Relay 1 (GPIO3), Send → switch it from the Relays tab.
  12. v2.73 ping: Status → Ping network. Contacts show by name with a CONTACT tag and a chat button; company units show REPEATER; strongest first with Good / Fair / Weak. Leave the page and come back → the last result is still there with “last ping N min ago”. The Contacts tab shows “in range” / “not heard”.
  13. v2.73: on device B, Settings → Network → tick “Let people nearby find me” and type a nickname. Ping from A → B shows the nickname and + Add sends a pairing request that B must accept. Untick it → B is a bare ID again and + Add asks for its code.
  14. v007.17 relay modes (Relays tab → Set up, or the unit's own Relays tab): Inching 2 s → switch on, it goes off by itself after 2 s and the page follows. Interlock → switching relay 2 on drops relay 1. Schedule a minute or two ahead → it switches at that time (the unit needs its clock). Local switch on Input 1 → shorting the input to GND toggles the relay.
  15. Check the pins before wiring anything: the default I/O pins are a first guess for the Heltec V4. Change them on the I/O tab if they clash with your board.

🔒 Company Mode & Tamper

Serial • v007 • persisted to NVS

Fresh v007 devices ship with the tamper module off (companyDevice = false). Enabling Company Mode sends the exact command COMPANY:ON over serial, which arms the case-lid / USB tamper watch and saves the flag to NVS so it survives reboots. Use Disable (COMPANY:OFF) to turn it back off.

Only enable this on owner-deployed company units. With tamper armed, opening the case (or, if VBUS-trip is on, attaching USB) will lock or wipe that device's own keys per its policy. Set the tamper policy first if you need WIPE vs LOCK.

Uses the connected USB device. If nothing is connected yet, your browser will prompt you to pick the device. Watch for COMPANY_OK in the status line above.

📡 Network Radio Power

Server-signed • v007.7+ • Ed25519

Sets the LoRa transmit power on company nodes across the mesh. The Worker signs the command with the company key; the connected device broadcasts it over serial and every company repeater relays & applies it. Leave Target blank to address all company nodes, or enter one node ID (8 hex) to change just one.

Max (22 dBm) is above the UK 868 MHz limit (25 mW ERP / 14 dBm) with the stock antenna. Only use Max in a genuinely enclosed / attenuated deployment where the radiated power at the antenna stays legal. Legal (14 dBm) is the safe default.

Requires your Write key (top of the page). Uses the connected USB device — connect a company node first. Watch for ADMIN_ACK lines confirming which repeaters applied the change.

Step 3 — Generate & Send

Over the mesh sends the licence by radio from the connected device to the device it was made for (the one whose MAC is in it) — no need to visit it. It uses the licence just generated, or the one pasted in Step 4. Both ends need v2.71 / v007.13 or newer. A licence is signed and tied to one MAC, so it is safe to send in the open.

Step 4 — Re-provision a re-flashed device

Flashing wipes the licence off a device, but the purchase still stands for that MAC. Paste the device's existing licence string here (or let Check for existing licence load it) and send it straight back — no new licence, no double charge.
