Test checklist

  1. Flash without erasing, unlock in the web page. Serial: [Vault] Storage encrypted with your PIN, STATUS shows VAULT:OPEN. Contacts, rooms and messages still there.

  3. Change PIN, reboot, only the new PIN works.
  4. Settings → Security → Lock storage now, then unlock.
  5. Serial CONTACTS while locked replies LOCKED.
  6. Only then, on one device: Bind storage to this chip (permanent), reboot, unlock.
